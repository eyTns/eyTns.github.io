# 새 페이지 등록 과정

이 레포에 새 앱/페이지를 추가할 때 거치는 등록 과정을 정리합니다. 에이전트 참고용입니다.

## 폴더/파일 구조
- 각 앱은 `앱폴더/` 아래에 둡니다.
- 진입 파일은 `index.html`로 둡니다. 루트에서 폴더 경로(`앱폴더/`)만으로 열립니다.
- 여러 파일로 나뉜 앱은 같은 폴더 안에 함께 둡니다. `index.html`이 상대 경로로 참조합니다.

## 루트 index.html에 링크 추가
- 루트 `index.html`의 링크 목록에 `<h3><a href="앱폴더/">표시이름</a></h3>` 한 줄을 추가합니다.
- 위치는 마지막 앱 다음, `레포지토리 페이지` 링크 앞입니다.

## README.md에 항목 추가
- `# 앱 소개` 섹션 안, 마지막 앱 다음이며 `# 계획` 앞에 항목을 추가합니다.
- 항목 형식
  - `## 표시이름`
  - `최근 업데이트: YYYY년 MM월`
  - `사용 툴: ...` (예: 클로드 코드 / 클로드 아티팩트 + 클로드 코드)
  - 설명 한두 줄
- 줄바꿈이 필요한 줄 끝에는 공백 두 개를 붙입니다.
- 출처 링크 등 부가 정보가 있으면 depth 2 목록으로 넣습니다.
- 항목 내용은 추측하지 않고 사용자에게 물어봅니다.

## 배포
- 이 레포는 `eyTns.github.io`라서 GitHub Pages가 이미 켜져 있습니다. 별도 빌드 설정은 없습니다.
- main 브랜치에 커밋·푸시하면 자동 반영됩니다.
- 커밋·푸시는 사용자가 직접 합니다. 에이전트는 하지 않습니다.
